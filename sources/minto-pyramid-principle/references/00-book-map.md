# Book map

> Source: Minto, *The Minto Pyramid Principle: Logic in Writing, Thinking and Problem Solving* (expanded edition; preface dated London 1996). Chapter theses are paraphrased. Page numbers are the printed book pages.

## The book's argument in one pyramid

```
Think first, write later: arrange your ideas as a pyramid under one governing thought,
test it against the pyramid rules, then render it on the page, the screen, or in prose
├── Part One — Logic in Writing: readers absorb ideas most easily top-down, so every
│   document should be a pyramid that answers one question the reader already has
├── Part Two — Logic in Thinking: each grouping must have a real logical order and a
│   summary that states its actual insight, or the pyramid is a facade
├── Part Three — Logic in Problem Solving: define the problem and structure the analysis
│   so the findings arrive already shaped for a pyramid
└── Part Four — Logic in Presentation: make the pyramid visible to the reader through
    headings, numbering, transitions, slides, and image-driven prose
```

The Preface states the payoff: forcing yourself to structure first should cut drafting time, increase clarity, and shorten the document. It also says Part One alone suffices for simple documents.
