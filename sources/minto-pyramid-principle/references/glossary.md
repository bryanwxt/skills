# Glossary

> Cross-cutting file. Minto's terms and the reference files' working labels, alphabetical. The file column says where the term is developed. Definitions are paraphrased.

| Term | Meaning | File |
|---|---|---|
| 30-second test | The reader should grasp the writer's whole thinking from about the first 30 seconds of reading. | 02, 10 |
| 90/10 ratio | A good deck is roughly 90% exhibits and 10% text slides. | 11 |
| Abduction | Peirce's form of inference: from an observed Result, via a known or hypothesized Rule, to a possible Case (cause) that must then be checked. | 09, 04 |
| Abduction, analytical | Abduction where the structure producing the outcome is known; the task is to find which part of it is causing R1. | 09 |
| Abduction, scientific | Abduction where the structure is absent, hidden, or contradicted by the outcome; the task is to hypothesize the structure and test it. | 09 |
| Action idea | An idea that tells the reader to do something (a step, recommendation, or solution). Contrast situation idea. | 06, 02 |
| Action ideas in disguise | Steps toward an effect dressed up as a class ("variables", "areas", "factors"). | 06 |
| Alternative objectives | Conditional recommendations (choose A if P matters most, B if Q does) used when no option delivers everything the reader wants. | 03b |
| Answer | The top point of the pyramid; the resolution of the introductory story and the reply to the reader's Question. | 01, 03 |
| Before / so that test | If action A is done *before* B, they are siblings; if A is done *so that* B can happen, A belongs beneath B. | 06, 05 |
| Before-after analysis | Drawing the current and the needed process side by side; their differences become the Key Line of a process-change document. | 03b |
| Benchmarking study | Problem situation where R2 is known but it's unclear whether the reader is at R1. | 07 |
| Bottom-up thinking | Building summaries upward: list the points, work out their relationships, draw conclusions. | 01, 02 |
| Build slide | A slide revealed in stages while the speaker explains, to show a complex relationship. | 11 |
| Business-press test | If a fact would appear unchallenged in the business press, the reader will accept it in a Situation. | 03 |
| Case / Rule / Result | Peirce's three elements: an observed fact, a belief about structure, and the expected outcome. | 09 |
| Chained deduction | Linked deductive arguments with obvious steps left out; allowed only when the reader will supply and accept them. | 04 |
| Changes vs steps | Key Line nouns: "changes" for fixing an existing system, "steps" for building a new capability. | 07 |
| Choice structure | A diagnostic framework of successive right/wrong forks mirroring a sequential process. | 08 |
| Class grouping | Items grouped because they share a characteristic, separated from everything that lacks it; ordered by degree. | 05 |
| Classification of causes | Suspected causes pre-grouped by similarity under a MECE top split. | 08 |
| Closed universe | When restructuring someone else's document, work only with what it says; clarify, don't judge or add. | 02 |
| Closer links | Sub-similarities within a long list that form subgroups before the top inference is drawn. | 06 |
| Complication | The development within the Situation that raises the reader's Question. It need not be a problem. | 01, 03 |
| Concern | A topic that worries the client but is not a yes/no question; contrast issue. | 08 |
| Crucial experiment | A test whose every outcome eliminates at least one hypothesis. | 08, 09 |
| Data-first analysis | Gathering all available data before defining the problem or framing hypotheses; Minto's foil. | 08 |
| Decimal numbering | 5 / 5.1 / 5.1.1 numbering of divisions, used alongside worded headings, never instead of them. | 10 |
| Decision tree / PERT diagram | Action-planning charts; they show the need for action, not the causes of a problem. | 08 |
| Deductive reasoning | A statement, a second statement commenting on the first's subject or predicate, and the "therefore" that follows from both. | 04, 01 |
| Deduction masquerading as induction | A causal chain (A led to B led to C) presented as a list of parallel items. | 04 |
| Degree order | Members of a class ranked by how strongly each has the shared characteristic, strongest first. | 05 |
| Diagnostic framework | A picture of the problem's structure (physical, financial, task, activity, classification, choice) used to locate causes through yes/no questions. | 08 |
| Directive | A memo asking or telling the reader to act; it plants rather than recalls the question. | 03b |
| Disturbing Event | The actual or prospective change (external, internal, or newly recognized) that unsettled the Opening Scene. | 07 |
| Dot-dash outline / lap visual | A terse outline, read page by page at a table, for progress reviews. | 10 |
| Drawing order | Ordering equal, simultaneous structural changes in the sequence you would draw the new structure. | 05 |
| End-product wording | Phrasing an action as the tangible result you would hold once it's done. | 06 |
| Exhibit questions (five) | What are the elements? How do amounts compare? What has changed? How are items distributed? How do items co-relate? | 11 |
| Find the nouns | A rewriting technique: keep the concrete nouns, picture how they relate, write that relationship as one sentence. | 12 |
| Four logical orders | Deductive (argument), chronological (time), structural, comparative (degree). Deductive groups take argument order; the other three govern inductive groups. | 01, 05 |
| Four question families | What should we do? Should we do it? How do we do it? Why (did it happen / not)? Most introductions answer one. | 03, 03b |
| Hard-headed thinking | The discipline of imposing logical order on every grouping and then making the inductive leap its similarity supports. | 05 |
| Hierarchical headings | Heading styles that shift and change form with each subordinate pyramid level. | 10 |
| Hierarchy of closed systems | Nested effect/cause groups in which each effect is a cause one level up. | 06 |
| Horizontal relationship | The logical relation among sibling ideas: deductive or inductive. | 01 |
| Hot buttons | The concerns that drive a client's decision makers when choosing among consultants. | 03b |
| Idea (Minto's sense) | A statement new to the reader that raises a question in their mind. | 01 |
| Improper class grouping | A "class" really derived from a process or structure, or one hiding subclasses. | 05 |
| Indented display | Parallel points set off and numbered inside a short memo; one such grouping per memo. | 10 |
| Inductive leap | Wording the implication of a grouping's similarity, often by visualizing the relationship. | 06 |
| Inductive reasoning | Grouping like ideas under one plural noun and inferring what their likeness implies. | 04, 01 |
| Intellectually blank assertion (IBA) | A summary that states only the number and kind of ideas below ("There are three problems"). | 06 |
| Introductory flow | The introduction as a story: Situation, Complication, Question, Answer. | 01, 03 |
| Invisible fences | Boundaries between sibling groups of headings; parallelism is required only within a group. | 10 |
| Issue | A question that can be answered only yes or no (from the legal sense of "at issue"). | 08 |
| Issue analysis | A 1960s decision method now used loosely for any analytical tree; Minto separates its valid core from the misconceptions. | 08 |
| Key Line | The row of ideas directly beneath the top point; it answers the question the top point raises. | 01, 02 |
| Layered problem | Repeated rounds of problem → solution → new problem (R1-a, R1-b…). Earlier layers fold into the Situation. | 07 |
| Leg | One branch running down from a Key Line point. | 01 |
| Level of abstraction | How general an idea is; a summary sits one level above what it summarizes. | 01 |
| Levels of action | Distinguishing sibling actions from the actions that produce them (see before / so that test). | 06 |
| Logic tree | A MECE breakdown of possible actions or opportunities, used to generate solutions and to audit grouped lists. | 08 |
| Magical number seven | Miller's finding that short-term memory holds about seven items, which motivates grouping. | 01 |
| Major Decision Variable (MDV) | A factor at a stage of a policy system that drives performance against objectives. | 08 |
| MECE | Mutually exclusive, collectively exhaustive: no overlaps, no gaps. Only MECE groupings can be summarized. | 05, 06 |
| Memory image | The piecemeal mental picture a reader builds while reading (Miller). | 12 |
| Mini-introduction | A brief S-C-Q story opening each Key Line section. | 03, 10 |
| Mini-process | A cluster of substeps producing one end product within a larger process. | 05 |
| Misfit | An item in an inductive group that doesn't fit the group's plural noun. | 04 |
| New Question | The question the top point raises in the reader's mind; the Key Line answers it. | 02 |
| News (vs thinking) | True facts that share nothing, so they support no inference. | 04 |
| Next Steps | A closing list of self-evident immediate actions; anything debatable belongs in the body. | 10 |
| Noncontroversial statement | One the reader understands and accepts immediately; the Situation's raw material. | 03 |
| Opening Scene (Starting Point) | The concrete, visualizable structure or process where the problem arose. | 07 |
| Other goodies | Incidental benefits of a proposal; mention them only if factual, never as the reason to act. | 03b |
| Overstructured argument | A deductive Key Line containing a step that raises no question; recast it inductively. | 02 |
| Paragraph point (¶) | A bullet mark for short lists or one emphasized paragraph. | 10 |
| Plural-noun test | Every idea in a grouping must fit under one plural noun (reasons, steps, problems…). | 01, 04 |
| Principle of division | The basis on which a whole is split (activity, location, product or market); it sets the structural order. | 05 |
| Problem Definition Framework | Opening Scene + Disturbing Event, R1, R2, and any solution layers, laid out before analysis. | 07 |
| Progress review | A phase-end report whose question is "what did you find?". | 03b |
| Put the text slide to work | Lay a text slide out as a diagram of relationships rather than plain bullets. | 11 |
| Question | The one question the Situation and Complication raise in the reader's mind; often left unstated, but always written down by the writer. | 01, 03 |
| Question/answer dialogue | The chain of reader questions and writer answers running down the pyramid. | 01 |
| R1 (undesired result) | The unwelcome outcome, or the opportunity, the reader faces. | 07 |
| R2 (desired result) | The specific, measurable outcome wanted instead of R1. | 07 |
| Reader projection | A reader who hasn't been given the summary first guesses one, often wrongly. | 04 |
| Recommendation Worksheet | Findings / Conclusions / Recommendations columns; rotate it so recommendations form the Key Line. | 04 |
| Referencing backward | Opening a section by echoing the key word of the previous one. | 10 |
| Reminding vs planting | Recalling a question the reader already has vs creating one they lack (directives, wide-audience pieces). | 03 |
| Rule of 32 | Viewing distance in feet ÷ 32 = minimum letter height in inches. | 11 |
| Self-sufficient statement | An opening sentence whose meaning needs nothing before it. | 03 |
| Sequential Analysis | Holland's five questions: Is there a problem? Where? Why? What could we do? What should we do? The first two feed the introduction; the rest feed the pyramid. | 07, 08 |
| Seven problem situations | The reader's possible positions relative to a solution, each with its own S-C-Q. | 07 |
| Situation | Accepted, noncontroversial statements about the subject, anchored in time and place, that open the introduction. | 01, 03 |
| Situation idea | An idea that tells the reader about something (a finding, fact, or conclusion). Contrast action idea. | 06 |
| Skeletal image | A picture reduced to shapes and arrows that captures only the relationships. | 12 |
| Source of the grouping | The analytical activity that produced a group (finding causes, dividing a whole, classifying); it determines the order. | 05 |
| Standard reasons | The Key Line of a funding request: it can't wait, it solves the problem, the numbers work, (plus factual extras). | 03b |
| Standard / direct / concerned / aggressive | Intro orderings S-C-A, A-S-C, C-S-A, and Q-S-C-A, each setting a different tone. | 03 |
| Standing in the same place | The goal of an introduction: writer and reader share a starting point before the argument begins. | 03 |
| Statement / comment / therefore | Minto's replacement for major premise, minor premise, conclusion. | 04 |
| Storyboard | A sheet of blank slide frames, each headed by its point, laid out before any slide is made. | 11 |
| Story form | The introduction's narrative arc: a known situation, a development, and its resolution. | 03 |
| Structural order | Order mirroring a visualized whole divided into parts. | 05 |
| Structural similarity | A shared kind of subject, predicate, or implied judgment across statements; the basis for an inference. | 06 |
| Structureless situation | An outcome that can't be explained because the structure producing it is absent, hidden, or contradicted. | 09 |
| Subject | What the document is about; the grammatical subject of the top sentence. | 02 |
| Sunset | Centered asterisks signalling that a conclusion follows. | 10 |
| Time order | A sequence of steps or causes producing an effect. | 05 |
| TOC as précis | Idea-stating headings turn the table of contents into a summary of the argument. | 10 |
| Top box | The apex of the pyramid: one sentence, Subject plus Answer. | 02 |
| Top-down ordering | Presenting a summary before the ideas it summarizes. | 01 |
| Underlined points | Every support point written in full and underlined, with levels shown by numbering and indentation. | 10 |
| Unique closed system | A MECE set of actions together with the exact effect they produce. | 06 |
| Vantage point | What the reader has just absorbed; it determines what a section introduction needs to say. | 03 |
| Vertical relationship | A point raises a question; the grouping beneath it answers it. | 01 |
| Visual recitation | Zelazny's term for text slides read aloud to the audience. | 11 |
| Visual thinking | Picturing structures and their consequences; needed for both hypotheses and experiments. | 09, 12 |
