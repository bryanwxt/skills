## 1. SCQA
An introduction exists to **remind** the audience, not to inform them. It tells a short story that brings them to the Question the deck answers.

- **Situation (S).** A statement about the subject that the audience knows or would readily accept. It anchors the story in a specific time and place. Test: the audience nods and thinks "yes, so what?"
- **Complication (C).** What happened in that Situation that creates tension. It is often a problem, but it can also be a change, a new opportunity, or a discrepancy. It is still something the audience recognizes.
- **Question (Q).** The question the Complication naturally raises. It is often left implied on the slides, but you must write it down for yourself.
- **Answer (A).** The governing thought: the top of the pyramid.

Each Key Line section of a longer deck gets its own mini-introduction, typically one sentence in the speaker notes or on a divider slide.

## 2. The four standard questions
| Situation | Complication | Question |
|---|---|---|
| We have a task to do | Something stops us from doing it | What should we do? |
| We have a problem | We know the solution | How do we implement it? |
| We have a problem | A solution has been proposed | Is it the right solution? |
| We took an action | It didn't work | Why not? |

Business decks rarely stop at "why?". The audience almost always wants to know what to do about it as well.

## 3. Common business patterns
Use these to *recommend* a structure to the user. The pattern predicts the Key Line.

**Giving direction (directive).**
S = We want to do X. C = To do it, we need you to do Y. Q = How do we do Y?
A question of "how" is always answered with **steps**, in time order. The Answer is the effect of completing the steps, which is roughly the reversal of the Complication.

**Seeking approval to spend money.**
S = We have a problem. C = We have a solution that costs $N. Q = Should I approve?
A = Approve it. The Key Line reasons are usually:
1. The problem can't wait.
2. This action solves it (or it is the best of the options examined).
3. The cost is more than offset by the benefits (the financial case).
4. Optionally, other benefits come with it. List these only if the facts support them.

**Explaining how to.**
The Key Line is **steps**. There are two variants:
- New capability: S = We must do X. C = We aren't set up for it. Q = How do we get set up?
- Fixing an existing process: S = The present process is X. C = It doesn't work properly. Q = What must change? To find the steps, lay out the current process and the recommended process side by side. The *differences* are the Key Line points.

**Choosing among alternatives.** Use this only when the audience already knows the options.
S = We want to do X. C = There are alternative ways to do it. Q = Which makes most sense?
- Preferred Key Line: the criteria. "Choose C: it is faster, cheaper, and easier to implement than A or B."
- If C doesn't win on every criterion: give one point per alternative, stating the main reason for C and the main reason each of A and B was dropped.
- If no option gives everything wanted: the answer is "it depends on the objective". Structure the Key Line around *alternative objectives* ("choose A if you want steady sales; choose B if you want quick profit"), not alternative solutions.

## 4. Consulting patterns
**Proposal to a new client.**
S = You have a problem. C = You have decided to bring in outside help. Q = Are we the right people?
A = Yes. The Key Line: we understand the problem; our approach is sound; we have relevant experience; the commercial terms make sense.

**Proposal to a known client.** Put the full problem description in S. C = You want help solving it. Q = How will you help? The Key Line is the approach, with experience woven into it.

**Progress review.**
S = We have been working on problem X, and last time we agreed to investigate Y. C = We have now done that. Q = What did you find?
A = The finding itself, stated so specifically that it could be wrong. Then the Key Line gives the supporting findings, followed by the implications and next steps.

## 5. Problem definition (for analytical or diagnostic decks)
Use this when the problem itself is fuzzy. Lay out:
1. **Starting point / opening scene.** The specific area where the problem arises: a process, a business, a market.
2. **Disturbing event.** What happened to upset that area's stability.
3. **R1: the undesired result.** What you don't like about what the area now produces.
4. **R2: the desired result.** What you want it to produce instead. Make it measurable where possible.
5. **What has been done so far,** if anything, about the gap.
6. **The Question.** What must be done to get from R1 to R2, given what has been tried.

Converting this to an introduction: read the elements from left to right and top to bottom. The Situation draws on the starting point and the disturbing event. The Complication draws on R1, R2, and what has been tried. The last thing the audience already knows is always the Complication.

Diagnostic frameworks for the analysis beneath the Key Line are:
- the physical structure of the area (how its units interact),
- cause-and-effect chains (the activities that produce R1),
- a classification of possible causes.

Form hypotheses, then find or request the data that proves or disproves them. Logic trees are useful for generating solutions and for spotting missing or overlapping items in a list.

There is strictly no such thing as "alternative solutions" to a well-defined problem. Either an action closes the R1→R2 gap or it doesn't. If the user asks for alternatives, check whether they actually mean alternative objectives, or options the audience already knows about.

## 6. Length and ordering
- The introduction's length follows what the audience needs. In a live deck, S and C usually take one or two slides.
- The deck should contain nothing in S or C that needs proof. If it needs an exhibit to be believed, it belongs in the body.
- Presentation orders: standard (S-C-A), direct (A-S-C, which opens with the answer for senior or impatient audiences), concerned (C-S-A), and questioning (Q-S-C-A). The thinking always starts from S. The delivery order is a choice about tone.
