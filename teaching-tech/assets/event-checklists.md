# Event checklists

Adapted from *Teaching Tech Together* (CC BY 4.0). Keep your own copy and update it after every event.

## Scheduling
- [ ] Format decided: in person / online for one site / online for several sites (each with local helpers)
- [ ] Expectations agreed with host(s), including who pays travel
- [ ] Audience decided: open / one organization / mixed; group sign-ups allowed
- [ ] Instructors and helpers confirmed (≈1 helper per 8–10 learners)
- [ ] Rooms booked (breakout rooms if needed); flat seating, power, sightlines, step-free access
- [ ] Dates set; travel booked
- [ ] Attendee list obtained and entered in registration

## Setting up
- [ ] Event page: date, time, location (with directions/parking), what to bring, level and sample exercise, code of conduct link
- [ ] Pre-workshop questionnaire sent (and non-responders followed up)
- [ ] Special needs checked
- [ ] Per-OS setup instructions published; reminder email sent 2 days before
- [ ] Video-conference link tested (online)
- [ ] Network access confirmed for every attendee
- [ ] Shared notes document created (with starter code and data)
- [ ] Welcome email with page link, readings, and prerequisite tasks
- [ ] Co-teachers: who teaches what, hand signals, switch points

## At the start
- [ ] Code of conduct reminder and reporting contact
- [ ] Introductions (teachers and learners)
- [ ] Attendance
- [ ] Sticky notes handed out (status flags, name notes)
- [ ] Setup check command run by everyone; helpers fix failures
- [ ] Collect any needed online account IDs

## During
- [ ] Formative check every 10–15 minutes
- [ ] Minute cards before each break; review them during the break
- [ ] Watch for learners falling behind; helpers circulate
- [ ] One-up/one-down at the end of each day

## At the end
- [ ] Attendance records updated (including instructors and helpers)
- [ ] Post-event survey sent
- [ ] "How you can help" invitation given (recruit from learners)
- [ ] Lesson notes and checklists updated with what went wrong
- [ ] Thank hosts and helpers

## Travel kit
Sticky notes · cough drops · comfortable shoes · notepad and pen · spare power adapter · video adapters · spare shirt · toiletries · snack · antacid · business cards · printed notes or tablet · insulated cup · spare glasses/contacts · portable Wi-Fi hotspot · whiteboard markers · laser pointer · wet wipes · USB drive with installers for each OS · exercise gear.
